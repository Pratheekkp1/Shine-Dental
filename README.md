# Shine Dental: Practice Website

Multi-page website for **Shine Dental**, a family dental practice in Winchester, VA.

**Live:** https://web1-umber-six.vercel.app

## Pages

- **Home:** about the practice, services, meet the team, a photo tour of the office, and contact details
- **Patient Forms:** downloadable new-patient paperwork
- **Appointment Policy:** scheduling, cancellation and late-arrival policies

## Features

- Appointment request form, plus a floating "Schedule" button that's always within reach
- Responsive layout for phones, which is where most patients look up a dentist

## Tech

HTML5 · CSS3 · vanilla JavaScript · Vercel

See also the [redesigned version](https://github.com/Pratheekkp1/ShineDental-demo).
